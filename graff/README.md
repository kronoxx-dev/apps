# Graff

Семейный мессенджер для Android: общий чат «Наша семья», личные переписки, группы, голосовые с локальной расшифровкой, редактирование и удаление своих сообщений у всех. Java/WebView + Node.js 24 + SQLite. Интерфейс поставляется внутри APK; сервер работает отдельно на Beget по адресу https://kronoxx.ru/graff/.

## Состояние 0.7.1

Добавлена семейная рация: онлайн и по локальной Wi-Fi-сети, с удержанием кнопки для передачи и прослушиванием при погашенном экране. Подробная инструкция ниже.

Голосовые сообщения, локальное распознавание русской речи и редактирование/удаление работают. Firebase подключён в APK 0.4.0 и на Beget. Реальная доставка Beget → FCM → Android при свёрнутом приложении проверена на изолированном тестовом аккаунте. Конфигурация Android и ключ сервисного аккаунта хранятся вне Git.

## Android

Android 8+ с актуальным Android System WebView и Google Play Services. Версия 0.7.1, versionCode 16. Технический applicationId `family.ryadom.app` сохранён для обновления старых установок; отображаемое название — Graff.

Установите APK поверх предыдущей версии, войдите. Для голосовых разрешите микрофон при первой записи. При первом запуске разрешите уведомления. Состояние push и переход в системные настройки доступны в **Настройки → Уведомления**. Нажатие на push открывает соответствующий чат. Браузерная версия пока не поддерживает Web Push.

В Android используются Firebase Cloud Messaging, канал «Сообщения Graff» и разрешение POST_NOTIFICATIONS. Уведомления работают при свёрнутом приложении и закрытом окне. После системной команды «Остановить принудительно» Android блокирует доставку до следующего запуска. Ограничения батареи производителя и сеть также влияют на доставку.

## Видеокружки

Кнопка записи в чате → режим камеры (короткое нажатие) → удержание. Разрешите камеру и микрофон, выберите переднюю или заднюю камеру, нажмите «Записать». До 60 секунд; остановка, просмотр со звуком, перезапись и отправка. При сворачивании активная запись отменяется и камера освобождается. Для воспроизведения нажмите кружок; повторное нажатие ставит на паузу. В меню своего кружка доступно удаление у всех.

Android и браузер используют MediaRecorder (WebM/MP4). Сервер через ffmpeg преобразует видео в квадратный MP4 H.264/AAC 480×480 и создаёт постер 240×240; интерфейс показывает круг. Лимит входного файла — 8 МБ, хранилища видео — 2 ГБ, одна обработка на процесс, таймаут 90 секунд. Требуется ffmpeg с libx264 и AAC. Видео и постеры лежат только в приватном `data/videos`; получение проверяет авторизацию и участие в чате. Удаление убирает оба файла. Повтор отправки с тем же nonce не создаёт дубль. Уведомление содержит «Видеосообщение». Расшифровка пока доступна только для голосовых.

## Голосовые и изменения сообщений

Удерживайте микрофон в чате, запишите до 2 минут, остановите, прослушайте и отправьте. Запись можно отменить. На Android используется AAC/M4A; браузер использует MediaRecorder. Аудио доступно только авторизованным участникам чата. Файлы хранятся в приватной папке `data/voice`, не раздаются напрямую через webroot.

После отправки Whisper.cpp 1.9.5 с многоязычной моделью base распознаёт русскую речь локально на Beget; запись и текст не отправляются внешнему сервису. Кнопка «Текст сообщения» раскрывает расшифровку, при сбое доступен повтор. Распознавание может ошибаться. Один процесс обрабатывает одну запись, используются 2 потока CPU; межпроцессная аренда в SQLite предотвращает параллельные тяжёлые задания. Максимум 20 ожидающих записей, 2 МБ на загрузку и 1 ГБ хранения голосовых; WAV для распознавания удаляется после успеха. Исходная запись сохраняется для прослушивания.

В меню «⋯» своего сообщения можно изменить текст или удалить сообщение у всех. Изменения синхронизируются при опросе открытых чатов по курсору ревизий. Отредактированные тексты отмечены «изменено». Голосовую запись можно удалить, но нельзя заменить её звук редактированием. Сервер проверяет авторство и защищает от одновременного перезаписывания устаревшей версии. При удалении очищаются текст/расшифровка и файлы аудио; техническая запись с идентификатором остаётся для синхронизации. Ранее сделанные резервные копии не переписываются.

Для самостоятельного подключения распознавания установите [Whisper.cpp](https://github.com/ggml-org/whisper.cpp) и [модель base](https://huggingface.co/ggerganov/whisper.cpp), задайте пути:

```sh
WHISPER_BINARY=/private/whisper-cli WHISPER_MODEL=/private/ggml-base.bin FFMPEG_PATH=/usr/local/bin/ffmpeg node server/server.mjs
```

Без этих параметров отправка и прослушивание аудио доступны при установленном ffmpeg, расшифровка помечается недоступной.

## Сервер и локальная проверка

Нужен Node.js 24 LTS, npm-зависимостей нет:

```sh
node server/server.mjs
node --test server/*.test.mjs
```

Откройте http://127.0.0.1:8787/; деморежим — `/?demo=1`. Для LAN: `HOST=0.0.0.0 node server/server.mjs`. Без Firebase-конфигурации чаты работают, push отключён. Первый одноразовый код владельца записывается в `data/first-invite.txt`. После регистрации владелец приглашает остальных кнопкой «+» рядом с фильтрами чатов.

Для включения отправки push:

```sh
GOOGLE_APPLICATION_CREDENTIALS=/private/firebase-service-account.json node server/server.mjs
```

FCM HTTP v1 использует короткоживущий OAuth-токен с областью firebase.messaging. Токены устройств привязаны к сессиям. Сервер отправляет уведомления только другим участникам чата; повторная отправка того же сообщения не создаёт повторного задания. Очередь сохраняется в SQLite в одной транзакции с сообщением, временные сбои повторяются с увеличением интервала до часа, срок доставки — 24 часа. Перед повторной отправкой проверяются сессия, членство и отметка прочтения. При выходе удаляются устройства сессии и их очередь, при смене аккаунта удаляются старые задания устройства. Серверные процессы используют аренду задания в SQLite, чтобы не отправлять его одновременно из разных процессов.

Задания обрабатываются после сообщения, при запуске процесса и каждые 5 секунд работающего процесса. Если хостинг останавливает простаивающий Passenger, оставшиеся задания продолжатся при следующем запуске процесса. Для гарантированных повторов в периоды простоя требуется постоянно работающий процесс/периодический запуск worker на хостинге.

## Сборка APK

1. JDK 17, Android SDK Platform 35, Build Tools 35.0.0.
2. В Firebase зарегистрируйте Android-приложение **family.ryadom.app**, скачайте его `google-services.json` в `android/app/`.
3. Используйте прежний keystore для обновления существующих установок. Секретные файлы исключены из Git.

```sh
export JAVA_HOME=/path/to/jdk17
export ANDROID_HOME=/path/to/android-sdk
export KEYSTORE=/private/graff.keystore
export KEY_ALIAS=ryadom-test
# Задайте KEYSTORE_PASSWORD в окружении, не сохраняйте в исходниках.
sh build-apk.sh
```

Результат — `build/graff-0.7.1.apk`. Для явно выбранной сборки без настроенного Firebase: `ALLOW_WITHOUT_FIREBASE=1 sh build-apk.sh`; в её настройках отображается «Пуши ещё не подключены». Gradle wrapper 8.11.1 проверяет SHA-256 дистрибутива. Firebase Messaging SDK 25.0.1. APK обновляет существующее приложение только с совпадающим сертификатом подписи.

## Данные

Пароли хешируются scrypt с индивидуальной солью. Сессионные токены и приглашения хранятся на сервере в виде хешей. Android хранит вход в AES-GCM/Android Keystore, браузер — в sessionStorage. Запросы проверяют членство в чате. Сквозного шифрования нет: сообщения доступны администратору сервера. Firebase получает сокращённый текст сообщения и заголовок для доставки push. На заблокированном экране используется закрытая версия уведомления «Новое сообщение».

Лимит текста — 4000 символов, сессия — 30 дней. Есть непрочитанные сообщения, пагинация истории, отметки прочтения и черновики текущего сеанса. Нет звонков, файловых вложений и восстановления пароля. История загружается с сервера; переписка требует соединения. Рация имеет отдельный локальный режим без интернета.

В репозитории нет базы переписки, паролей пользователей, ключа подписи APK и ключа сервисного аккаунта Firebase.


## Семейная карта

«Локация» заменяет вкладку «Семья». Кнопка «+» справа от фильтров чатов открывает прежнее создание и копирование одноразового приглашения; создавать коды может владелец семьи.

Карта Leaflet 1.9.4 с тайлами OpenStreetMap показывает аватарки участников, точность GPS и время последней точки. Если участник ещё не включил передачу, его карточка показана без выдуманных координат. Близкие друг к другу аватарки объединяются рядом, чтобы не перекрывать друг друга. Для карты нужен интернет; атрибуция OSM сохраняется. В APK идентифицирован User-Agent Graff; браузер отправляет origin referrer. Никаких загрузок карт для офлайн-использования нет.

Каждый участник включает передачу своей локации отдельно. На Android запрашиваются георазрешения, затем запускается location foreground service с постоянным уведомлением и кнопкой «Остановить». Передача продолжается при свёрнутом приложении; обновление примерно каждые 30 секунд, в зависимости от GPS и системы. Автоматического запуска после перезагрузки или принудительной остановки нет — нужно снова включить передачу. Система экономии энергии Samsung может влиять на частоту. В браузере используется Geolocation API, обновления доступны пока открыта страница.

Доступ к `/api/locations` только у авторизованных участников семейного чата. Передача привязана к пользователю, сессии и случайному идентификатору согласия. Запросы с прежним идентификатором после остановки отклоняются. Хранится одна последняя точка без истории маршрутов; точки старше 24 часов удаляются. После остановки точка удаляется при успешном запросе к серверу; при отсутствии сети последняя точка остаётся с временем обновления, максимум 24 часа. Выход из сессии удаляет связанную точку. Устаревшие точки не выдаются за положение в реальном времени.


## Фото и эмодзи (0.5.0)

Скрепка в чате открывает выбор изображения. На Android используется системный выбор документа `image/*`, без разрешения на чтение всей галереи. Можно отправить одно фото за сообщение: предпросмотр, необязательная подпись до 4000 символов и отправка. Изображение уменьшается до 1920 px по длинной стороне, переводится в JPEG до 2 МБ; исходник для выбора ограничен 32 МБ. Android 9+ использует ImageDecoder, старые версии — BitmapFactory с обработкой ориентации EXIF. Прозрачность становится белым фоном, анимация — статичным изображением.

На сервере JPEG проверяется и повторно кодируется ffmpeg, создаётся миниатюра 480 px, метаданные не копируются. Файлы хранятся вне webroot; полный размер и миниатюры доступны только через авторизованный API участникам чата. Подпись можно изменить, фото удалить у всех; удаление убирает оба файла. Уведомления показывают «Фото» и подпись. Изображения открываются крупно с кнопкой увеличения. Доступ к изображению из чужого чата запрещён.

Смайлик рядом с текстом открывает панель эмодзи с категориями и часто используемыми символами. Эмодзи вставляются в позицию курсора; недавние сохраняются только на этом устройстве. Обычная системная клавиатура с эмодзи также работает, в том числе в подписях фото.

Для тестов изображений нужен ffmpeg: `FFMPEG_PATH=/путь/к/ffmpeg node --test server/*.test.mjs`.

## Управление записью в 0.6.1

Короткое нажатие на микрофон переключает его в камеру, повторное возвращает микрофон. Удержание запускает запись; отпускание после начала записи открывает предпросмотр. Если при первом использовании появился запрос разрешений, можно продолжить кнопками «Записать» и «Остановить» в открытом окне. Enter на кнопке запускает запись с клавиатуры. Скрепка теперь открывает только галерею.

У видеокружков собственная тёмно-зелёная заставка с кнопкой Play. Иконка push — фирменный знак Graff; в строке состояния Android отображает его одноцветную маску.

## Graff 0.7.0 — семейная рация

Android: вкладка «Рация», два явно выбираемых режима. Все слушатели должны сами войти в канал. Удержание большой кнопки открывает микрофон; отпускание, уход с экрана или сворачивание прекращают передачу. Максимум 30 секунд за нажатие, до 8 устройств. Прослушивание продолжается в foreground service с постоянным уведомлением и кнопкой выхода; сеанс автоматически завершается через 2 часа. Звонок/потеря audio focus отключает канал. Голосовые/видеозаписи требуют сначала выйти из рации.

- **Онлайн**: текущая авторизация Graff и членство в семейном чате, HTTPS relay через `/api/radio/{join,poll,claim,frame,release,leave}`. Канал полудуплексный, захват эфира атомарный между процессами Passenger. Никаких push для скрытого запуска микрофона.
- **Рядом**: войдите в Graff до поездки. Подключите телефоны к общей Wi-Fi-сети или точке доступа одного телефона; интернет не требуется. На одном телефоне «Создать канал рядом», на остальных «Подключиться по коду». Передайте полный код через «Передать код» (например Quick Share / Bluetooth) или скопируйте. Хост должен оставаться включённым в канале. При создании нового канала генерируется новый ключ. Локальные имена берутся из сохранённого профиля, онлайн-проверки аккаунта в этом режиме нет: доступ определяется владением кодом. Держите код внутри семьи. Изоляция клиентов на гостевой Wi-Fi-сети может блокировать связь. Режимы переключаются после выхода из текущего канала; автоматического перехода нет.

Звук: PCM16 mono 16 kHz, пакеты по 250 мс. Это живая передача с небольшой задержкой и ограниченным буфером; задержка/потери зависят от сети. Во время речи примерно 43 КБ/с на отправляющий поток с учётом base64 (плюс протокол), аналогично на каждого слушателя; сжатия Opus пока нет. Передачи не становятся сообщениями и не транскрибируются.

Онлайн audio buffer отделён от переписки: `radio.mjs` использует SQLite в `/dev/shm` на Linux (RAM), ограниченный временной буфер до 2 секунд, очистка каждую секунду, lease эфира 2.5 секунды и присутствие 6 секунд. На macOS/dev временный relay SQLite находится в dataDir, `secure_delete=ON`; это не архив эфира. Main DB backup не включает буфер рации. HTTPS шифрует транспорт до сервера, сквозного шифрования онлайн-режима нет.

LAN relay — временный TCP-сокет внутри Android foreground service, в памяти, с AES-256-GCM. Ключ входит в локальный код, для каждого пакета случайный IV, AAD разделяет направления, ответы привязаны к запросу; защита от повторов и просроченных запросов. Время на телефонах должно отличаться не более чем на минуту. Для локальных подключений на Android 8–15 используются INTERNET/ACCESS_NETWORK_STATE и обычная локальная сеть; приложение не создаёт точку доступа автоматически. Wi-Fi/Bluetooth settings и доступность локальной сети зависят от телефона.

Сборка APK: прежняя подпись, package `family.ryadom.app`, versionCode 15 / versionName 0.7.0. Новые foreground service permissions: MICROPHONE и MEDIA_PLAYBACK; WAKE_LOCK для активного сеанса. Сервис не exported, не перезапускается автоматически после остановки/перезагрузки. В Android 16+ с принудительной защитой локальной сети может требоваться отдельная адаптация разрешений; текущий targetSdk 35.

## UI 0.7.1

Play в предпросмотре кружка центрирован по ширине. Кнопки «Камера» и «Записать» имеют общую высоту 56 px, отправка в чате — круг 48×48 px. Экран рации адаптируется к доступной высоте без прокрутки: код подключения вводится в отдельном диалоге, создатель открывает код кнопкой «Пригласить». Передача и копирование кода сохранены.
